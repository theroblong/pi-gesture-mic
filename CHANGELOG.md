# Changelog

## Pi 5 v1 (v6 engine port)

- Added Raspberry Pi OS 64-bit / X11 controller adapter and installer.
- Preserved dual-hand gestures, pinky ownership switching, wrist cursor mapping, configurable tracking area, and telemetry.
- Added webcam and USB microphone diagnostics, Chromium kiosk launcher, and desktop autostart.
- Added repository documentation and reproducible standalone release ZIP.

This release is an integration prototype; Pi hardware validation remains outstanding.
